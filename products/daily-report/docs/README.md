# Daily Report 文档索引

文档按用途分为四类：

- `architecture/`：聊天分析架构与 CLI 重构设计。
- `guides/`：媒体导出、项目维护和中文使用说明。
- `operations/`：备份、交接、日常运维与微信版本兼容资料。
- `releases/`：V1.0 发布说明与历史项目状态。
- `reports/`：包含真实微信资产信息的本机报告，不提交到 Git。

建议先看 [项目 README](../README.md)，需要媒体导出时看 [MEDIA_EXPORT_GUIDE.md](guides/MEDIA_EXPORT_GUIDE.md)。
