# Cashew 与米汝：安装及首次配对

两个安装包已成功构建，服务端账本功能已上线。2026-10-14 已确认 Cashew 418 完成全量上传，并修复服务器误将普通已支付账单判为“跳过”的问题。

**推荐组合：Cashew 418 + Miru 0.3.4（7）。** 418 修复首次上传，见 [配对问题修复记录](cashew-miru-pairing-fix-20261014.md)；Miru 7 增加前台自动刷新，服务器同步修复状态分类，见 [统计与刷新修复](cashew-miru-classification-fix-20261014.md)。已配对用户无需重新配对。

## 1. 安装前保存账本

先在原 Cashew 导出一份完整备份并保存到“文件”。沿用原来的侧载工具及同一个 App/LiveContainer 容器进行更新，保留原应用数据；不要先卸载或删除旧容器。IPA 仍是未签名包，安装方法与以前相同。

## 2. 安装两个新版

| App | 版本 | 构建下载页 |
|---|---|---|
| Miru | 0.3.4（7） | [Codemagic #70](https://codemagic.io/app/6a7d2b2285432d3d8f060eea/build/6acf3ff1a90f016d29d0d5c3) |
| Cashew | 5.4.3（418） | [Codemagic #21](https://codemagic.io/app/6a106336e948beff964378b5/build/6acf04f312cce3cb996488c3) |

进入构建页的 Artifacts 下载 Miru.ipa 或 Runner.ipa。本机保存位置为 `data/finance-classification/Miru-0.3.4-7.ipa` 和 `data/finance-build/Cashew-5.4.3-418.ipa`。

Cashew 保留你上次构建使用的中文导入修复，未改变本地数据库 schema 46。安装后先打开 Cashew，确认原来的账单仍在，再连接同步。

## 3. 首次配对

1. 打开手机 Tailscale，保持能够访问你现有的米汝服务。
2. 打开新版 Miru，进入侧边栏“我的账本”，点“连接 Cashew”。页面显示服务器地址和一次性配对码。
3. 打开新版 Cashew，在“设置 → 米汝同步”中填写上述地址和配对码，连接。配对码十分钟有效，仅用一次。不要填写 Miru 的聊天/管理令牌。
4. 保持 Cashew 在前台，等待显示“已同步 N 笔账单”。首次会上传全部现存记录，包括转账、待支付等状态。
5. 回 Miru 打开“我的账本”（已打开则自动检查更新，也可下拉刷新）。核对总笔数、最近几笔标题/金额/日期/账户；分别按币种核对同口径收支。

完成后可直接问米汝：“这周花了多少钱？”“餐饮花了多少？”“查昨天的账单。”回答以最后成功同步时间为准。

## 4. 日常使用

继续在 Cashew 记账。它在前台记账后约 3 秒发起自动上传；离线时先保留在本机，下次联网并打开 Cashew 后重试。LiveContainer 用户等同步完成后再切换 App。Miru 回到前台时检查更新，账本页可见时每 10 秒检查一次并显示最后同步时间，不保证 Cashew 关闭后仍持续后台上传。

本周按上海时区、周一开始。实际收支排除未支付、跳过、转账、余额调整、借贷及未来记录；全部明细仍可查看这些记录。不同币种分别显示。照片附件暂不上传；单次上限 16 MiB / 10 万笔，超限会明确报错并保留云端上一版。

恢复备份后重启 Cashew。如 Miru 出现“需要核对”，先检查手机内账本和笔数，再点“核对并采用”。重新配对会撤销旧上传凭据；撤销上传权限会保留已同步的只读账本。
